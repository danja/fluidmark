Make a mark

Type an identifier and mark a music file with it. The mark is mixed into the audio and the file is written to your computer. You can also mark a file you are given.

Up to 63 characters. A URL or IRI works well, because that is what a mark is for.

Tones are audible and are the original scheme, kept for compatibility. The watermark scheme is inaudible and is the one to use.

WAV, MP3, FLAC, OGG or M4A. Nothing leaves this page.

About this

This is a port and extension of WebBeeps, Danny Ayers' audible tone watermarking, which was live at webbeep.it and did the same two jobs in the same page. The tone scheme is unchanged so that old files still read. The watermark scheme is new and is what the site is for.

Everything runs in this page: the audio is decoded here, the codec is here, and nothing is sent anywhere. How it works has the detail.
